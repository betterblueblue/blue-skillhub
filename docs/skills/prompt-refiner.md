# prompt-refiner（提示词打磨）

运行：`/prompt-refiner` 后面直接跟你的原话或已有提示词。[技能 README：快速开始、与 IntentAnchor 怎么选](../../skills/prompt-refiner/README.md)。

## 它做什么

把你想让 AI 做的事写成一段可复制的指令。它只交付提示词，不执行里面的任务；收到提示词的 Agent 不需要安装这个技能。

## 什么时候用

例如：`/prompt-refiner 帮我写个提示词，比比这两个宽带哪个划算，我只装一年。`

## 常见问题

**第一句我也说不清，怎么办？** 直接说。例如“让 AI 帮我优化首页”，它会问你最希望解决什么问题；你说“手机上找不到预约按钮，只想要修改建议”，它就直接写提示词。同一任务最多追问两轮，每轮一件事。两轮后仍拿不准，或你随时说“先给一版”，它都会停止提问，给你一份标明假设的草稿。

**它和 IntentAnchor 有什么区别？** 要一段马上能转发的任务指令，用这个技能；要决定一个项目为谁做、哪些功能要保留，并把决定留给后续开发，用 [IntentAnchor](intent-anchor.md)。两者独立，没有先后要求。

## 用对了是什么样子

上例的关键是“只装一年”：宣传月费更低，不一定意味着用满一年停用时花得更少。默认直接给成品，例如：

```text
根据两份宽带报价，比较使用 12 个月后停用的总支出。分别列出优惠期内外的月费、安装费和届时适用的解约费，给出两条算式和差额。报价没写清的费用单列，不按零算；如果还没收到报价，先向我索取。
```
