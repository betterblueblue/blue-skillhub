# VL 识图（utility）

> 调用外部视觉语言模型 API 识别图片，让不具备视觉能力的模型也能读截图、设计稿、架构图和报错图片。工具型 utility，不参与链路评测体系。

运行：`/vl-vision`（模型可自动触发）｜技能本体：[skills/vl-vision/](../../skills/vl-vision/)

## 它做什么

- 把本地图片发给视觉语言模型，返回结构化的文字描述与信息提取。
- 供主流程消费：设计稿还原、截图比对、报错截图分析等场景，图片里的信息转成文字后交给当前任务。
- 关键结论要求回源核实：识图结果是指示，不是证据——涉及代码、数据的关键结论要回到源码或原图确认。

## 什么时候用

- 当前任务的输入是图片（设计稿、界面截图、报错弹窗、架构图），而正在干活的模型看不了图。
- 不需要用：模型本身有视觉能力时直接看图即可；纯文本任务。

## 常见问题

**需要什么配置？**
需要可用的视觉模型 API 及其密钥，配置方法见技能目录内的说明文档。

**识别结果可信吗？**
作为线索可信，作为证据不行。页面上写着的字和实际代码里的字段可能是两回事，关键结论必须回源核实。

**会泄露图片内容吗？**
图片会发送给所配置的外部模型服务；涉及敏感信息的截图先脱敏再识别。

## 用对了是什么样子

- 图片信息被转成了结构化文字结论，并标注了来自哪张图。
- 下游任务引用识图结果时，关键项在源文件或原图上复核过。
