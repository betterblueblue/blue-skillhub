# prompt-refiner（提示词打磨）

把随口说的需求、零散笔记或一段不好用的旧指令，整理成能直接发给另一个 Agent 的提示词。接手的 Agent 不需要安装这个技能。

## 快速开始

```text
/prompt-refiner 让 AI 看看这两个月的客服反馈里，哪些退款问题被不同客户反复提到。我要带去开产品会，不用给客户写回复。
```

你拿到的是一段分析指令，不是分析结果。它会写清楚：按不同客户计数，同一人反复催促不算多人，只整理会议材料。把指令和反馈记录一起交给能读这些材料的 Agent 即可。想看改动理由，或同时拿 PRO 版和精简版，调用时说明就行。

## 选 prompt-refiner 还是 IntentAnchor？

**看你现在需要拿走什么，不看需求有多大。** 同样是客服反馈：

| 你现在想做的事 | 选哪个 | 得到什么 |
|---|---|---|
| “明早要开会，帮我把分析退款反馈的要求说清楚。” | `/prompt-refiner` | 一段可复制的任务指令。这次要做什么、用哪些材料、怎样算做好，都写给接手的 Agent。 |
| “想做个反馈工具，还没想好给客服还是产品经理用，第一版该保留什么。” | [`/intent-anchor`](../intent-anchor/README.md) | 一份经你确认的 `intent.md`，记录目标、能力取舍和不可妥协项，供后续 PRD、设计与开发使用。 |

两者独立，不需要先跑一个再跑另一个。要是材料齐了，你想让当前 Agent **直接分析并给结果**，直接交代任务就好，两个技能都不用。

第一句话不用写得完整。只有答案会改变任务方向才会追问，每轮一件、同一任务最多两轮。你随时可以说“先给一版”，拿一份标明假设的草稿。
