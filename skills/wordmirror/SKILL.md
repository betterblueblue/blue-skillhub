# 言镜 · wordmirror · 认识我

这个 skill 干一件事：让你在任何 AI 里开工时，它都认识你——你是谁、在忙什么、跟你说话要守什么规矩；你随口问"我说过啥"，它能翻出原话、带日期。你的话全部存在自己电脑上，不上传。

## 数据在哪

**全局层**（你是谁：你的情况 / 规矩 / 你说的话 / 月报）——不分项目，跟着你走。怎么找到：
1. 环境变量 `WORD_MIRROR_HOME`
2. `~/.wordmirror/bind.json` 里写的位置（`ds.py bind <目录>` 接上已有数据）
3. `~/.wordmirror/`
4. 都没有 → `~/.wordmirror/`（第一次用时建）
详细见 `references/data-locations.md`。

**项目层**（这个项目的事：说过要做的事）——在哪个目录干活就记哪：`<当前目录>/.wordmirror/promises.jsonl`。

数据就位后，主力文件在数据目录 `data/` 下：
- `corpus_dedup.jsonl` 你说的每句话，每行一条 `{agent, date, proj, sid, msg}`
- `user_writebacks.jsonl` 你确认过的事实
- `profile/portrait.md` 你是谁；`profile/habits.md` 跟你说话的规矩
- `chroma_index/` 按意思搜用的索引（可选，建过才能按意思搜）

## 加载时先做：认识你

读 `data/profile/portrait.md` 和 `habits.md`。读不到 = 数据还没生成 → 走 `references/init-protocol.md` 初始化。

读完，开工前瞄一眼（合计不超过三句话，说完就干正事）：
1. **欠着的事**：项目层 + 全局层 `promises.jsonl` 里 status=open 的，挑最老一件提一句"你 X 天前说的 XX 还没下文"
2. **情况新不新**：portrait.md 顶部日期超 30 天 → 提一句"你的情况 X 天没更新了，要不要补点最近的"
3. 两条都没有 → 直接干正事

## 每类事怎么做

大部分活你用自己的本事（读、搜、写文件）就能干。有**三件活你干不了**——按意思搜、生成网页、提取存档——那才调工具，见下面"三件干不了的活"。

### 查你说过的话
用户问"我之前说过什么 / 我上次怎么想的 / 某话题我的观点 / 哪些事没下文"：
1. 到 `data/corpus_dedup.jsonl` 里搜。你直接搜就行；用户记不清自己当时用的词是常态，同义词、口语变体都试一轮
2. 命中的话按日期排，结论先行，引文带日期和当时的 agent
3. **字面怎么都搜不到** → 调按意思搜（见下），前提是建过索引；没建就先问用户要不要建
4. 用户问"前后说法变了吗" → 取这个话题最早、最近两条并排摆出来，**别替他判断哪个对**
查不到就直说查不到，绝不编。详见 `references/query-protocol.md`。

### 记事 / 写回
用户亲口确认的事实才记："我决定了 X""这事完了/黄了""不是 22 万是 20 万"。你的推断、他随口的情绪、"我在想要不要"都**不记**。拿不准就问一句"这个要记吗"。
- 说要做的事 → `python scripts/ds.py promise add "事"`；做完了 `promise done 关键词`，不做了 `promise drop 关键词`
- 确认过的事实 → `python scripts/ds.py wb add "事实" --topic 主题 --ref 依据`
**这两类写操作只走命令，不要自己手写 jsonl**——命令保证格式对、坏行拦得住。写完当场回一声"记下了：X"。详见 `references/writeback-protocol.md`。

### 把情况分享给别的 AI
用户说"把我的情况告诉这个 AI / 出一页能贴走的"：
1. 只读 `data/layers/public.md`（能对外那份），**绝不碰 portrait.md 完整情况**
2. 按 `references/privacy-rules.md` 把隐私去掉（姓名/公司/薪资…）
3. 你自己拼一份随身说明书 md 给用户，告诉他贴到哪个 AI 对话开头就能用
对外发的东西，发之前把要发的清单给他过目、他点头才发。

### 更新数据 / 重新提取
用户说"更新数据 / 重新提取 / 我的情况过期了" → 走 `references/ingest-protocol.md`，跑 `python scripts/ds.py ingest`（提取存档是重活，见下）。你说过的话变多了，补一句 `python scripts/ds.py vec build --update`（建过按意思搜的话）。

### 生成网页
用户要看"月度报告 / 说过要做的事 / 翻给你看"这些页面 → 跑 `python scripts/render.py all`（生成网页是重活，见下），出完告诉他文件在哪、双击就能看。

### 首次初始化
读不到 portrait.md → 走 `references/init-protocol.md` 四步：探测存档 → ingest 提取 → 你照着模板整理出 portrait.md + habits.md → 念给用户听、当场纠错。

## 三件干不了的活（才调工具）

| 活 | 工具 | 什么时候调 |
|---|---|---|
| 按意思搜（算向量，你现场算不了） | `python scripts/vecsearch.py query "问题"` / `build` | 字面搜不到、用户记不清原词时 |
| 生成网页（要样式一致，你现写会漂） | `python scripts/render.py read / monthly / tracker / all` | 用户要月度报告 / 看板 / 翻给你看 |
| 提取存档（要啃好几个 AI 的原始记录 + 去重） | `python scripts/ds.py ingest` | 首次初始化 / 更新数据 |

## 硬规则（任何时候）

1. 引用用户原话必须带日期；编他没说过的一次都不行——引文只从搜出来的原话里取，不从记忆里默写
2. 用户数据只在自己电脑用，不进任何外部请求——除非他当次明确说"可以"（见 `references/privacy-rules.md`）
3. 数据目录怎么找：见 `references/data-locations.md`（按机器定位，不写死路径）
4. **加载或初始化收尾，必须亮一次家底**：一句话告诉他这 skill 还能出月度报告、说过要做的事的网页、随身说明书。不超过一句，他说不用就停
5. **记账 / 写回只走命令**（`promise` / `wb`），不手写文件——格式和坏行拦截在命令里
6. **不主动分析、不评判用户**：你的情况和说过要做的事是给你干活用的背景，不是拿来回敬他的。不主动输出"我注意到你最近……"式观察，不对他的决定做"更成熟 / 在逃避"式点评。他要复盘时只摆事实和数据，不下诊断

## 主动引导（功能要让他知道，别闷着）

用户不知道这 skill 能出什么，不引导他永远不知道：
- 首次认识完他，收尾带一句家底（硬规则 4）
- 刚整理完 portrait / habits、月底月初、或他聊到"这个月干了啥"，各补一句对应的（月度报告 / 说过要做的事的网页 / 随身说明书），不超过一句，他说不用就闭嘴
- 出了任何网页产物，告诉他文件在哪、双击就能看
