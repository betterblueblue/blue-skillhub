## 1. 视觉主题与气质

一种模式，一套脸。言镜的所有产物——首页、你的情况、月报、翻给你看、说明书、说过要做的事——
都是同一本"文艺杂志"的不同栏目：读信页是散文版块，看板是数据版块，纸张相同、字号不同。

**零外联铁律**：所有产物是 file:// 双击可开的单文件。禁止 webfont CDN、禁止任何外部请求。
字体靠系统字体栈优雅降级——产品宪法第三条在视觉层的延伸。

## 2. 颜色与角色

```yaml
colors:
  primary:        "#cc785c"   # 话印朱：全站唯一强调色。品牌铭牌、引文竖线、链接、选中行指示
  primary-active: "#a9583e"   # 按压/悬停变体
  canvas:         "#faf9f5"   # 页面底色：暖纸白，刻意不用冷灰白
  surface-soft:   "#f5f0e8"   # 侧栏、软色带、行悬停
  surface-card:   "#efe9de"   # 卡片底、选中行（比 canvas 深一档）
  hairline:       "#e6dfd8"   # 1px 边线（同族一档高度差，不是墨线）
  ink:            "#141413"   # 标题主色：暖墨，不是纯黑
  body:           "#3d3d3a"   # 正文
  body-strong:    "#252523"   # 重点段、引文
  muted:          "#6c6a64"   # 次要文字、眉标
  muted-soft:     "#8e8b82"   # 脚注、落款
  on-primary:     "#ffffff"   # 朱色底上的文字
```

### 状态色语义（全站唯一一套，含义不许变）

```yaml
semantic:
  stalled:    "#c64545"   # 搁置 30 天+：红。欠账要扎眼，但不闪烁不加粗恐吓
  cooling:    "#d4a017"   # 自然冷却：琥珀。承认现实，不是失败
  waiting:    "#5db872"   # 等外部结果：绿。球不在自己手里
  done:       "#8e8b82"   # 已收线：灰。安静退场
```

## 3. 字体

**零 webfont，全靠系统栈。**

```yaml
type:
  display:  "'Noto Serif SC','Source Han Serif SC','Songti SC',SimSun,Georgia,serif"
            # 衬线：大标题、品牌铭牌、引文。字重 400，负字距 -0.5~-1.5px
  body:     "'PingFang SC','Microsoft YaHei','Noto Sans SC',-apple-system,'Segoe UI',sans-serif"
            # 正文与数据页 UI。读信页 16px/1.7，看板 13px/1.5（密度变体）
  mono:     "'JetBrains Mono',Consolas,'Cascadia Code',ui-monospace,monospace"
            # 日期、编号、ID、眉标、计数
```

**字号层级：** display 48/36/28px（衬线 400）→ 标题 22/18px（黑体 500）→ 正文 16px →
辅助 14px → 眉标 12px（mono，字距 +1.5px）。看板密度变体：13px 基准，标题 15-24px。
**大数字：** 34-48px 衬线 400，配一句人话注解，不许裸数字。

## 4. 核心组件

### 引文块（灵魂组件）

- 左侧 3px 朱色竖线 + mono 全日期眉标（YYYY-MM-DD，禁止月日省略）
- 引文用衬线，出处标注 `YYYY-MM-DD · 某某agent`——"引用必须带日期"在排版层的执行

### 顶部铭牌（全站统一）

每页左上：衬线"言镜"字标（链回 index）+ mono "wordmirror"副标。看板在侧栏头部同款。

### 卡片 / 色带

surface-card / surface-soft 底、12px 圆角、内边距 24-32px、无阴影。

### 状态徽标

药丸形小字，只用状态色四档，不发明第五种。

### 大数字块

数字大、注解小、人话先行。"1,917 条——这个月你对 AI 说了这么多话"。

### 看板行与抽屉（数据密度变体）

三栏布局（侧栏 220px + 列表 + 抽屉 360px）保留，但令牌全站统一：侧栏用 surface-soft，
选中行 surface-card + 左缘 3px 朱线，日期/计数一律 mono，抽屉引文与读信页引文块同规格。

## 5. 布局

- 间距基元 4px：4/8/12/16/24/32/48/96
- 读信页：正文最大宽 720px 居中，分节留白 96px
- 看板：三栏满幅，行高 1.5，密度优先；移动端抽屉改底部弹层

## 6. 深度与阴影

**色块优先，阴影稀有。** 层级靠 canvas/soft/card/hairline 四档表达。
唯一允许：`0 1px 3px rgba(20,20,19,0.08)`，仅悬停抬升。禁止大投影、发光、渐变。

## 7. 规矩与禁区（Do & Don't）

**必须：** 引文必带全日期；状态只用四档语义色；每页落款 `言镜 · 数据只存在你自己的电脑上`；
每页有顶部铭牌；行高 ≥1.55。

**文案说人话，不堆术语也不抖机灵：** 用户看得见的每个字都用大白话（「你说的话」「重复的只算一次」「按意思搜」），
不出现「语料/画像/蒸馏/去重/语义索引/向量/脱敏」这类内部词；也不写「你的话只住在这台机器上」这种硬凹的口号——该说事实就直说事实（比如「数据只存在你自己的电脑上」）。

**禁止：** 冷蓝色系与紫色强调（v1 的薰衣草紫已废）——言镜的温度是差异化；装饰性渐变、
玻璃拟态、大投影；webfont/CDN/外部请求；裸数字没有注解；日期省略成 "06-06"。

## 8. 给 agent 的快速提示词

> 做言镜产物页面：读本文件。全站暖纸白 #faf9f5 底 + 衬线标题 + #cc785c 话印朱唯一强调；
> 看板是同体系密度变体（13px、三栏、mono 数据）。引文块带 mono 全日期眉标。
> 状态色只用 stalled红/cooling琥珀/waiting绿/done灰。零外部请求，系统字体栈。
> 落款"言镜 · 数据只存在你自己的电脑上"。文案说人话，不堆术语，也不写硬凹的口号。改样式先改本文档再动模板。
