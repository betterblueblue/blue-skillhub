# 查你说过的话 · 检索协议

> 触发场景：用户问自己的历史观点、决定、口头禅、某话题的想法、哪些事没下文。
> 核心原则：**回答里的每一句"我说过 X"都要有日期**，查不到就直说查不到。
> 引文纪律：引文只从你**实际搜出来的原话**里取，不从记忆里默写——默写就可能编。

## 数据在哪

先按 `references/data-locations.md` 找到数据目录。要搜的主力文件：

| 想查什么 | 文件 | 每行长啥样 |
|---|---|---|
| 我说过的话（主力） | `data/corpus_dedup.jsonl` | `{agent, date, proj, sid, msg}` |
| 我后来确认过的事实 | `data/user_writebacks.jsonl` | `{date, source, topic, msg, ref}` |
| 某次对话的来龙去脉 | `data/sessions.jsonl` | 会话卡：我问了什么 + AI 结论 |
| AI 当时回了什么 | `data/ai_messages.jsonl` | 量大，按 sid 关联再查 |

## 怎么搜（你自己来，不用命令）

**第一步：直接搜主力文件。** 用 grep / 读文件都行：

```bash
grep "关键词" <数据目录>/corpus_dedup.jsonl
```

**用户记不清自己当时用的词是常态**——同义词、口语变体都试一轮。比如他问"我放弃那事儿了吗"，就去搜 放弃 / 不做了 / 算了 / 砍了；问求职，搜 求职 / 找工作 / 投简历 / 面试。多词分别搜再取交集，中文直接搜。

**第二步（按需）：加限定。**
- 按时间："上个月 / 7 月" → `grep '"date": "YYYY-MM' corpus_dedup.jsonl`（把 `YYYY-MM` 换成目标年月，如 `2026-07`）
- 按项目："我备考那会儿" → 先按 `proj` 字段定位（备考 / jobsearch…），再在结果里搜关键词

**第三步（字面怎么都搜不到才用）：按意思搜。** 这是三件"你干不了的活"之一（算向量，你现场算不了），调工具：

```bash
python <skill目录>/scripts/vecsearch.py query "你的问题"
```

前提建过索引（`data/chroma_index/` 存在）。没建就先告诉用户、问要不要建（`vecsearch.py build`）。

**什么时候值得用按意思搜（适用场景）：**
- 用户只记得大概意思，不记得原词。例：用户问"我之前为什么换技术栈"，实际原话是"把老项目迁到 Go"。
- 用户换了一种说法。例：用户问"我有没有放弃过那件事"，实际用词是"先不搞了 / 算了 / 砍了"。
- 用户记不清当时用的简称、代号或项目名，只记得这段经历大概涉及什么。
- 跨语言或口语变体：用户用更书面的问法，实际说的是更口语的原话。

**谁触发：** 由你（Agent）判定字面检索不足后自行调用，不要求用户提供命令。用户只需要用自然语言提问。

**没建索引怎么办：** 先告诉用户按意思搜需要一次性安装依赖并建索引（`python <skill目录>/scripts/vecsearch.py build`），建好之前退回字面检索，照常回答但不打包票能按意思找到。

## 回答怎么给

- 先给结论，再给原话引文（带日期和当时的 agent / 项目）
- 同一件事前后说法变了 → **两版都摆出来，标好日期，别替用户判断哪个对**（取最早、最近两条并排即可）
- 只有孤证 → 说明"就找到这一条"
- 什么都没搜到 → 直说没找到，不编。这是硬规则

## 典型问法对照

| 用户问 | 你怎么搜 |
|---|---|
| "我上个月纠结的事后来怎么样了" | 搜当月 纠结/犹豫/要不要，再往后追同话题 |
| "我对 RAG 的观点是什么" | 搜 RAG/向量/检索，按时间排，展示观点变化 |
| "我说过要做但没下文的事" | 看两层 `promises.jsonl` 里 status=open 的，按天数排 |
| "我说话有什么口头禅" | 看 `data/stats_wordfreq.json`（通用词表高频词频率，脚本算好的；注意是常用词统计，不是用户独有口头禅识别） |
| "把我 7 月 7 号干的事还原出来" | 搜 `"date": "YYYY-MM-DD"`（换成目标日期，如 `2026-07-07`），按会话分组复述 |
| "前后说法变了吗" | 取这个话题最早、最近两条并排，不下结论 |
