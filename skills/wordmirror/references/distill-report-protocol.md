# 报告蒸馏协议 · 判断还给 Agent，脚本只做确定性

> 触发场景：ingest 跑完、用户说"更新报告 / 重新整理 / 报告过期了"、或首次初始化。
> 原则：**报告页由你（Agent）读语料后用人话写。脚本只产候选素材，不替你下结论。**
> 六页结构（0.2 版）：01 你是谁 / 02 那几条线 / 03 说话算数 / 04 你没看见的 / 05 AI 眼里的你 / 06 这几个月。
> **⚠️ 照见（insights.jsonl）是另一份活，走 `mirror-protocol.md`——更新报告时和这几份一起定稿，别只写 MD 漏了照见复核。**
> 脚本给的 materials_*.json / stats_*.json 是"线索"，不是"成品"——你要自己抽读语料核实、滤掉假阳性。

## 先看这个：有料还是凑数

用户看这些页，是想被**照见**——看见自己没意识到的自己。**一句总结如果他自己都能猜到，就是凑数。**

| 凑数（重写） | 有料（照这样） |
|---|---|
| 你话比较短 | 你给 AI 下指令大多 20 字以内，一句一个活，像对熟练工下工单 |
| 主要项目：A 项目、B 项目 | 6 月你说了句「先把手上这个收掉再说」，之后那条线真的收了 |
| 你爱提问 | 你会反问 AI 的推理——「你凭什么说这两件事是一回事」 |
| 你说话直接 | 你会直接怼回去——「别我说什么你都附和」（YYYY-MM-DD） |

> 表中右列是**示意**，不是可抄的成品：真实写作时，原话和日期必须从语料里实际搜出来，不许照抄示意句、不许凭记忆默写。**skill 包里不许出现任何真实用户的原话**——示例一律用示意句。

**三条硬规矩：**
1. 每个判断都要配一条**能撑起它的原话**，而且挑**最带劲的那句**，不是最普通的那句。
2. 优先写**反差和转折**（A 方向→B 方向、想法→发布、等结果→收线），不要平铺直叙的总结。
3. 写不出原话的，宁可删掉，不许用"大概 / 可能 / 比较"糊过去。

## 大白话宪法（这些页面全部是给人看的）

1. 标题、小节名、正文，全部写给"人"看：读出来要像对一个同事说话。
2. 禁内部词：语料 / 画像 / 蒸馏 / 语义 / 向量 / 归档 / 管道 / token / 数据源……换成"你说的话 / 你的情况 / 整理 / 按意思搜"这类平常话。
3. 禁翻译腔、禁口号腔（"赋能、闭环、体系化"），禁只有 agent 自己懂的缩写。
4. 写完自检：把每节标题和每段开头**念出来**，别扭就重写；宁可短，不可绕。

## 要写的文件（都在数据目录 data/profile/ 下）

| 文件 | 对应页 | 回答什么问题 |
|---|---|---|
| portrait.md | 01 你是谁 | 你现在在哪、在忙什么、怎么跟你共事（含「你总让 AI 干什么」一节） |
| lines.md | 02 那几条线 | 每条线：怎么起的 → 哪里拐的 → 现在停在哪 |
| promises.jsonl（账本） | 03 说话算数 | 说过要做的事，后来各自怎么样了（走 `wm.py promise`，不手写） |
| noticed.md | 04 你没看见的 | 这期你读完才知道的事（硬指标落点） |
| insights.jsonl（账本） | 04 | 挂着的有据反差；每次更新复核一遍 |
| ai-eyes.md | 05 AI 眼里的你 | 各工具场景卡 + AI 对你的观察，合并一页 |
| timeline.md | 06 这几个月 | 页首本期对账，往回走到开始的地方 |

**这几份里，promises 只走命令；其余由你写/改。旧版页面（决定 / 反复提的事 / 总让 AI 干什么 / 各 AI 样子 / AI 怎么看你）已并入上面结构，它们的 MD 以「-历史」后缀保留供对照，不再更新。**

## 硬指标（每期验收，不凑数）

每次更新报告，**至少产出 1 条"你读完才知道的事"**——写进 noticed.md，并当面念给用户确认；他认了才算数。**连续两期产不出**，说明找发现的方法要修（比如抽读范围太窄、只看了统计没读原话），停下修方法，不许拿"你话比较短"这类废话凑页。没有新发现的一期，noticed.md 诚实写"这期没有"，空态比假发现强。

## 04 的生产方式（三步）

04 页不再是"机器抓句子贴上来"。机器候选（word_drift、正则 say_do）只是线索，大概率是假阳性：

1. **带着问题去找**：每次更新时，你带着一个明确的问题去抽读最近的原话——"这期有什么是他自己可能没意识到的？"三个老方向不变（说了没做 / 前后说法相反 / 习惯突变），但证据必须是你从原话里挖出来的，带日期、能当场反查。
2. **旧账复核**：insights.jsonl 里挂着的每条，重验"现在还成立吗"。不成立了（比如"那条线没再提"但最近又冒出来了）→ status 改 `archived` 并写明复核依据；还成立才留在页上。过时的落差比没有落差更伤信任。
3. **找不到就承认**：这期真没有，noticed.md 写"这期没有"；连续两期没有，修方法。

## 各文件怎么写

### portrait.md（01 你是谁）

结构：基本情况 → 这几个月在忙什么（表）→ 现在最要紧的事 → 干活的脾气（条条有原话）→ 还没想明白的地方（照实记）→ 这版改了上一版什么 → 你总让 AI 干什么。版本号递增（v1、v2…），改了上一版的结论要认账写明。数字（条数、分工具统计）只作背景。

### lines.md（02 那几条线）

把你手上的事**一条线一节**，节标题带状态，状态只有三种：**还在走 / 已经收线 / 没了下文**。每节写：起点原话 → 带日期的后续事实 → 一段克制的承接。不解释原因、不下诊断；"没了下文"不等于放弃，如实写"还没见到动工的记录"即可。线的数量宁少勿滥——四到六条为宜，凑不满就少写。

**每条线末尾写一句 `现在的问题是：…`**：用白话把这条线当前的岔路或悬而未决的点摆出来，不下结论、不问动机。写不出就留空，不硬凑；渲染会把它收成一条更醒目的收束块。

### noticed.md（04 你没看见的）

每期一节（标题带期间）。每条发现 = 一句白话点题 + 带日期的原话证据 + 一段克制承接。用户已确认的标注"你已看过、默认成立"。这期没有就写"这期没有"。

### ai-eyes.md（05 AI 眼里的你）

两半合一页：`## 在这里，你是什么样`（每个常用工具一张卡：`### 工具名：一句人话` + 主要在干 + 怎么说话 + 一条代表原话）；后面接观察栏目（`换了 AI，你也换了一种说法` / `不同 AI 都看见了这一点` / `AI 这样看你` / `AI 也看错过你`（必须同时有 AI 原话和用户纠正） / `现在，AI 应该这样认识你`）。AI 的描述是观察材料，不是人格诊断。

### timeline.md（06 这几个月）

页首 `## 本期对账`：跟上期比，新开的动作、变化、还悬着的事、新出现的习惯、教训——五行以内，每行有据。之后按时间阶段写回望（重点写**转向和变化**，阶段标题用人话），再接白话栏目（`以前的你，后来的你` / `原来这两句话有关` / `这句话后来去了哪里` / `现在你停在这里`）。引文格式必须是 `「用户原话」（YYYY-MM-DD）`，从语料实际检索后复制，不凭记忆改写。

### note.md（首页 · 给现在的你）

这不是七页之一，是首页顶部那封"这期只说一件事"的短笺。它替你把当下最值得停下来看的一件事摆出来，让人一打开就感到"AI 读过我的话"。

- **只写一件事**：这期最值得停下来想的一件事，一个点子，别塞三件。
- **至少两条带日期的原话当证据**，从语料实际搜出；写不出就留空态，不硬凑。
- **不诊断、不定性**：不说"你其实 / 你一直 / 你总是"这类绝对化语气，不贴标签、不推断动机。
- 一句白话点题 + 证据原话 + 克制承接（承接可留白）；结尾一句话交回给你，结论权归用户。
- 用户认可才算数；**被否过或纠正过的点，之后不再自动出现**。

模板示意（示意句，不出现真实原话）：

```markdown
<一句点题，四十字内，只这件事>

「<原话>」（YYYY-MM-DD）
「<原话>」（YYYY-MM-DD）

<承接一句，白话；或留空>
```

## 共同规则

1. 用 `## 小节` 分节，**不要写 `# 大标题`**（HTML 页自己会放大标题）。
2. 引用原话必须带日期（YYYY-MM-DD），从语料（用户的话）或 ai_messages.jsonl（AI 的话）里**实际搜出来**的，不许凭记忆默写。
3. 每个判断都要有依据：至少一条原话 + 日期；拿不准的标"（推断）"或干脆删掉。
4. **滤假阳性**：脚本候选里混着指令文本、代码、讨论稿、客套话——读一遍挑出来丢掉。
5. 没有料就写一句"还没什么可说的"，不硬凑字数。
6. 全文用「你」称呼用户：页面是 Agent 整理给用户看的，标题和小节名一律用第二人称——引号里的用户原话除外。

## 写完之后

1. 跑 `python scripts/render.py all` 刷新六页——**脚本只排版，写完 MD 不重跑，页面不会自己变**。
2. 把 noticed.md 的新发现念给用户，请他确认有没有说错，当场改；硬指标以他确认为准。
3. 这几份 MD 是快照，不会自动更新——说过的话变多了、要重新整理时，重跑本协议。
