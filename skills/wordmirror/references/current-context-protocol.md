# 当前情境协议 · 给 Agent 的轻量状态

> 这不是画像，也不是报告。它只回答：你现在在做什么，这次更适合怎么帮你。

## 什么时候更新

只在用户明确做了决定、当前主线变化、工作阶段切换，或用户明确说一件事完成/搁置/不做时更新。不要每条消息都改。

## 怎么写

写可观察的工作事实，不写心理诊断或性格判断。保留最近一次更新日期；内容控制在一页内。

```markdown
# 当前情境

- 更新于：YYYY-MM-DD
- 当前主线：<正在推进的事情>
- 当前阶段：探索 / 决策 / 执行 / 验证 / 收尾 / 复盘 / 闲聊
- 最近明确决定：<决定；没有就写暂无>
- 当前最要紧的事：<下一件必须推进的事>
- 当前更需要的支持：更多信息 / 一个取舍 / 直接执行 / 风险提醒 / 找历史依据
- 暂时不要：<用户明确不想做或不想听的事；没有就删掉>
```

## 加载规则

新会话先读它；读不到时不编造，按当前对话临时判断。当前情境只给 Agent 作回应依据，不单独渲染成 HTML。
