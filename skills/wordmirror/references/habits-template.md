# habits.md 模板 · "跟我干活的规矩"怎么写

> 初始化时由 AI 按这个结构整理，写到**数据目录**（不是 skill 包里）。
> 频率数字必须来自 data/stats_wordfreq.json（脚本算的），禁止目测。

```markdown
# 跟我干活的规矩（给 AI 看的）· v1

> 从 <N> 条原话里整理（<生成日期>）。

## 怎么跟我说话

1. <规则——从你说过的话里找依据，如"先说结论，再给细节">
（5-8 条；每条能追溯到原话证据）

## 我常说的词（次数是从 <N> 条话里数的）

| 我说 | 次数 | 意思 |
|---|---|---|
| <词> | <数字> | <一句话解释——注意：高频词不一定都是口头禅，区分"习惯用语"和"信号"> |

（只收 10-15 个真正高频的；次数抄 stats_wordfreq.json）

## 跟我搭伙的节奏

- <协作模式：怎么开工、怎么确认、怎么收尾>
（3-5 条，从用户实际行为模式提炼）

## 家里的事 / 特殊场景（如有）

- <家庭相关任务线、用户的特殊偏好——你没说过就不写这节>
```

## 从哪取材

- `data/stats_wordfreq.json` → 词频表（唯一数字来源）
- `data/stats_agents.json` → 分 agent 特征（用户在不同工具里的差异）
- 抽你说过的"教 AI 干活"的话 → 怎么跟我说话的规则
