## 1. 视觉主题与气质

参照对象 developers.openai.com（实测截图提取）：**开发者工具平台的克制与精准**，
不是营销页的戏剧感。言镜的主题不变——私人档案、安静回望——但视觉语言换成工具级：
留白节奏、灰阶层级、组件精度，靠这些建立高级感，不靠颜色和装饰。

气质：干净、安静、克制、可靠；不是杂志、不是海报、不是终端，是"一本好用的私人工具书"。

**零外联铁律**：所有产物是 file:// 双击可开的单文件。禁止 webfont CDN、禁止任何外部请求、
禁止任何位图（v7 起 hero 晨景画已弃用，不再嵌图）。所有质感来自 CSS 本身。

## 2. 颜色与角色

```yaml
colors:
  bg:      "#FFFFFF"   # 页面底：纯白
  surface: "#F9F9F9"   # 灰底卡片
  surface-2:"#F1F1F2"  # hover / 更深一档
  fg:      "#0D0D0D"   # 标题、引文、数字（近黑）
  fg-soft: "#404046"   # 引文正文
  muted:   "#6E6E74"   # 正文次级
  faint:   "#9B9BA1"   # 眉标、日期、微元数据（只配 ≥14px 字）
  border:  "#EBEBED"   # 1px 边框/行线
  accent:  "#10A37F"   # 绿：只准做 3px 状态点（进行中/时间线节点），禁做文字色、禁做大面积
```

**纪律（v7 最大的变化）：**
- **无渐变、无色场**——页面任何地方不准出现渐变背景（用户实测否决："塑料感、不高级"）。
- 绿色不进正文、不进按钮、不进大面积。视觉锚是**黑色胶囊按钮**（导航右侧，对应基准的 API Dashboard）。
- 高级感来源：留白节奏 > 灰阶层级 > 组件精度。颜色越少越档。

### 状态色（尽量中性化）

```yaml
semantic:
  # v7 徽章全部中性灰调，不再用红琥珀绿彩字；进行中可用绿点 + 中性字
  live:   "绿点 3px + 中性文字"
  done:   "灰底中性文字"
  open:   "灰底 + 1px 边框中性文字"
```

## 3. 字体

```yaml
type:
  display:  "-apple-system,'SF Pro Display','Segoe UI Variable','Segoe UI','PingFang SC','Microsoft YaHei',sans-serif"
            # 标题、引文、大数字。字重 550-600（不是 700），字距 -0.01 ~ -0.03em
  body:     "-apple-system,'SF Pro Text','Segoe UI Variable','Segoe UI','PingFang SC','Microsoft YaHei',sans-serif"
  mono:     "ui-monospace,'SF Mono','Cascadia Mono',Consolas,monospace"
```

**字号层级（收敛，基准是 44px 级不是 80px 级）：**
hero 标题 clamp(1.9rem, 3.4vw, 2.75rem) 600 居中 → 章节标题 clamp(1.4rem, 2.4vw, 1.8rem) 600 →
节眉标 .75rem mono 大写 → 正文 15.5px → 辅助 .84rem → 眉标 mono。
大数字 1.75rem 600，配人话注解。**全站字重最高 600，禁止 700+。**

## 4. 核心组件

### 导航（sticky）

白底毛玻璃 + 1px 底线。左：wordmark 文字（无 logo 圆点）。中：章节锚点胶囊
（当前节浅灰胶囊）。右：**黑色胶囊按钮**（视觉锚，如「↗ 本地档案」）。

### Hero（居中，唯一）

居中标题（≤2.75rem）+ 一段灰色说明 + **大数字带**：白卡 1px 细边框 + 16px 圆角 +
四格发丝线分格。hero 是全页唯一的居中排版区，其余全部左对齐。

### 两种卡片（全站只有这两种容器）

1. **灰底卡 `.card-gray`**：#F9F9F9 底、16px 圆角、无边框无阴影。用于"反复在意"卡阵、
   镜像引用、步骤卡、右栏面板。
2. **白底细边框卡 `.card-line`**：白底、1px #EBEBED 边框、16px 圆角、无阴影。
   用于"我是谁"格阵、"说过·未落地"清单、大数字带。

### 引文块 `.quote`

灰底卡内：mono 日期眉标（faint 色）+ 墨色引文。无边框竖线（v6 的左竖线已弃）。
"引用必须带日期"的排版执行不变。

### 进度条 `.meter`

3px 高圆角，**墨色填充**（不是绿）。底 #F1F1F2。

### 时间线 `.tl`

1px 竖线 + 空心圆点；"进行中"节点绿实心、今天节点墨色实心。

### 徽章 `.badge`

全中性：灰底 / 灰底+边框，中性文字。状态语义靠文字，不靠颜色。

## 5. 布局

- 单页统一结构：导航 → hero（居中）→ 双栏（主栏六节 + 右栏 sticky）→ 页脚
- 内容最大宽 1200px；右栏 19rem
- **节分区（B 方案）：节 = 超大 24px 圆角色块，奇偶灰/白交替**（01/03/05 灰、02/04/06 白）；
  灰底节内的灰卡、提示条、徽章、排行轨道自动反转成白底，分隔线加深一档（rgba(13,13,13,.09)），
  弱色文字加深到 muted/fg-soft 保对比度；白底节靠留白换气，无边框
- 节间距 clamp(3.2rem, 7vh, 5rem)；移动端右栏落到正文下方、卡片单列
- 锚点导航：导航胶囊 + 右栏索引都指向本页 #锚点，**无跨页跳转**

## 6. 规矩与禁区（Do & Don't）

**必须：** 引文必带全日期；每节有眉标+标题+一句副题；数据缺失写诚实空态（不凑数）；
行高 ≥1.6；键盘焦点可见；prefers-reduced-motion。

**禁止（v7 新增）：** 任何渐变背景/色场/渐变文字；绿色做文字、按钮、大面积；
700+ 字重；大投影、发光、玻璃拟态卡片（导航毛玻璃除外）；hero 图片（v7 起不嵌图）；
纯黑 #000；跨页跳转链接。

## 7. 给 agent 的快速提示词

> 做言镜产物页面：读本文件。纯白 #FFF 底 + 近黑 #0D0D0D + 灰阶 #F9F9F9/#6E6E74/#EBEBED；
> 绿 #10A37F 只做 3px 状态点；黑色胶囊按钮是唯一视觉锚；两种卡片（灰底/白底细边框）；
> 无渐变、无图片、字重 ≤600；单页锚点导航。
