# 律刃 RuleBlade

律刃是一组写给 AI 编码助手的通用行为规则（当前版本 v3.4）：8 条编码规则、1 条评审与迭代纪律、1 条中文表达要求。它解决的不是"模型会不会写代码"，而是执行问题：没有弄清需求就动手、漏查调用方、顺手修改无关代码、把测试失败归咎于环境，或者用生硬的内部术语向用户解释结果。

规则正文在本技能目录的 [CLAUDE.md](CLAUDE.md)，这是唯一的事实来源；本文件只负责安装引导，不复述规则内容。

## 使用方法

1. 读取本技能目录下的 `CLAUDE.md`（规则正文）。
2. 征得用户同意后，把该文件的完整内容写入目标项目根目录：
   - Claude Code 用户 → `CLAUDE.md`
   - Codex 用户 → `AGENTS.md`
3. 若目标项目根目录已存在同名文件，不要直接覆盖：把律刃内容作为一节追加，或提示用户自行合并，冲突处由用户决定。

## 与其他技能的关系

- 律刃约束通用的编码行为；IntentAnchor、Pathfinder、ImpactRadar 等技能负责各自的需求澄清、项目摸底或影响分析流程。两者可以配合，也可以单独使用。
- 规则偏向谨慎。小改动会按第 8 条缩短检查范围；涉及数据库、接口、权限、状态机或多个模块时，要求先把影响范围查清楚。
